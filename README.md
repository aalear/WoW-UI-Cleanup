# UI Cleanup

This addon tweaks a few things I personally find wildly annoying about the (mostly) in-combat UI in World of Warcraft. Namely:

- The damage and healing numbers over player and pet unit frames scale weirdly with scaling the frames themselves and honestly I just don't care for the visual noise. So those are hidden now.
- If you enable the Self Highlight, it's on by default, but I just want it in combat when I choose to enable it. So this addon toggles it off on login and allows the use of the keybind to turn it back on.
- The cooldown manager is generally handy, but hell if I can remember what every buff or cooldown does across multiple classes. Mouseover tooltips are available but reading them all the way in the corner mid-combat is annoying. So this addon will anchor Cooldown Manager tooltips at the cursor.
